# Number Guessing Game

## Description
This is a Java console application developed as part of the Oasis Infobyte Java Development Internship.

## Features
- Random number generation (1–100)
- User input
- Too High / Too Low hints
- Correct guess message
- Attempt counter
- Maximum 7 attempts
- Play Again option
- Score tracking

## Technologies Used
- Java
- IntelliJ IDEA
